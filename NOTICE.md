The reference generates a hotel-search URL from location, dates and guest count. It does not implement local reservations. YangSlots uses this as a small input-workflow reference; its Java resource model, database transactions, capacity sweep, expiring holds, idempotency, private sessions, exports, tests and interface are new implementations. No CrewAI, browser automation, hotel search, external booking or language model runs in this service.
